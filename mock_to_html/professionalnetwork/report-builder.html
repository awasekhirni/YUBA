Q4 Hiring Performance by Department
Source: job_listings ⨝ job_applications ⨝ companies
● Valid SQL
◆ Columns (Group By)
company_department✕ job_category✕ fiscal_quarter✕
◆ Metrics (Aggregate)

◆ Filters (WHERE)

Sort & Limit
Generated SQL
SELECT
  c.company_department,
  j.job_category,
  j.fiscal_quarter,
  COUNT(a.id) AS total_applications,
  AVG(a.time_to_hire_days) AS avg_time_to_hire,
  COUNT(a.accepted) AS offers_accepted
FROM job_listings j
JOIN job_applications a ON a.job_id = j.id
JOIN companies c ON c.id = j.company_id
WHERE j.posted_at >= '2024-10-01'
  AND j.fiscal_quarter = 'Q4 2024'
  AND j.region IN ('ZA','KE','NG')
GROUP BY 1, 2, 3
ORDER BY 4 DESC LIMIT 50;
